# Installation Guide

VaultEscape is a premium HTML/CSS/JS template. Because it is static and does not require complex build steps, installation is straightforward.

## Requirements

- A modern web browser (Chrome, Firefox, Safari, Edge)
- A code editor (like VS Code, Sublime Text, or WebStorm)
- (Optional) A local web server like Live Server for the best development experience.

## Steps to Install

1. **Extract the Files**: Unzip the downloaded template package to a local directory on your machine.
2. **Open the Project**: Open the extracted folder using your code editor.
3. **Run Locally**: 
   - If using VS Code, install the "Live Server" extension. Right-click on `index.html` (or `template/index.html`) and select "Open with Live Server".
   - Alternatively, you can simply double-click any `.html` file to preview it directly in your browser.

## Deployment

To deploy VaultEscape, upload all files and folders (including `assets/`, `pages/`, etc.) to your web hosting provider or a static hosting service like Vercel, Netlify, or GitHub Pages. No Node modules or compilation steps are needed.
