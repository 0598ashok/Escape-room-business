# Support

If you experience any issues or have questions regarding the modifications and structure of this template, please reach out to our support channel.

## Before Submitting a Ticket
- Ensure you have read the [Installation Guide](installation.md) and [Customization Guide](customization.md).
- Check your browser console for any JavaScript errors.
- If assets aren't loading, ensure the file paths in your HTML `src` or `href` attributes correspond correctly to your root directory.

## Getting Help
When reaching out to support, please provide:
1. A clear description of your issue.
2. The specific file and line number (if encountering a code bug).
3. The browser and operating system you are using.
4. Screenshots or error logs if visually applicable.
