# Credits & Acknowledgements

The VaultEscape template utilizes industry-standard libraries and tools to deliver a premium experience. 

## Technologies Used
- **HTML5 & CSS3**: Core markup and styling base.
- **TailwindCSS**: Primary utility-first CSS framework for layout styling and rapid customization.
- **JavaScript (ES6)**: Functionality, state, and interaction handling.

## Libraries
- **GSAP (GreenSock Animation Platform)**: Powering timeline animations, scroll-linked interactions, and elements reveal.
- **Framer Motion**: Mentioned in logic for specific React integrations (if ported by the user).
- **Lucide Icons**: Clean, scalable SVG icons utilized across the interface.

## Fonts
- **Google Fonts**: Standardized web-safe and modern typography. Fonts should be downloaded locally into `assets/fonts/` for strict guideline adherence and performance.

All placeholder imagery is sourced from commercially free databases (such as Unsplash or Pexels) and should be replaced with native, optimized assets before public traffic is routed to the site.
